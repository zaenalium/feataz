# Comprehensive Code Review: feataz Library

## 1. Executive Summary

feataz is an ambitious and well-structured Polars-native feature engineering library with an impressive breadth of transformers (40+). The codebase demonstrates solid understanding of feature engineering concepts and Polars expressions. **Strengths**: comprehensive transformer catalog, consistent sklearn-style API, good separation of fit/transform logic, lightweight dependencies. **Maturity level**: Early-stage (v0.1.0), suitable for personal/experimental use but needs hardening for production. **Top 3 highest-leverage opportunities**:

1. **Add LazyFrame support** - Currently all transformers only work with eager DataFrames, severely limiting scalability for large datasets
2. **Implement proper base class with validation mixins** - Significant code duplication across transformers for column inference, validation, and state management
3. **Comprehensive edge case handling** - Missing tests for high cardinality, unseen categories, constant columns, empty DataFrames, and numerical stability

## 2. Critical Issues (P0 – fix immediately)

### 2.1 **LeaveOneOutEncoder has data leakage in transform** (encoders.py:866-873)
**Priority: Critical | Effort: Low**

```python
# Current implementation (LEAKAGE):
enc = ((pl.col("sum_t") - pl.col(self.target)) / (pl.col("cnt") - 1)).alias("_tmp_loo")
```

The transform method uses `self.target` from the *input* DataFrame to compute leave-one-out encoding. This is correct for training data but creates leakage when transforming test data where target may not exist or be different.

**Fix:**
```python
# In transform, check if target exists and warn, or use stored statistics differently
if self.target in df.columns:
    # Use target from input (training mode)
    enc = ((pl.col("sum_t") - pl.col(self.target)) / (pl.col("cnt") - 1))
else:
    # Use stored per-category mean (inference mode) - fall back to global mean
    enc = pl.col("sum_t") / pl.col("cnt")
```

### 2.3 **BoxCoxTransformer/YeoJohnsonTransformer use `map_elements` (slow)** (vst.py:331-342, 422-435)
**Priority: Critical | Effort: Medium**

Using `map_elements` with Python lambdas is extremely slow compared to vectorized operations.

**Fix:**
```python
def transform(self, df: pl.DataFrame) -> pl.DataFrame:
    out = df
    for col in self.feature_names_in_ or []:
        lam = self.lambdas_[col]
        offset = self.offsets_[col]
        new_col = f"{col}{self.suffix}"
        x = (pl.col(col).cast(pl.Float64) + offset)
        if lam == 0:
            expr = x.log()
        else:
            expr = (x.pow(lam) - 1) / lam
        out = out.with_columns(expr.alias(new_col))
        if self.drop_original:
            out = out.drop(col)
    return out
```

## 3. High-Impact Improvements (P1)

### 3.1 **Create ColumnInferenceMixin and ValidationMixin** (base.py, all modules)
**Priority: High | Effort: Medium**

Every module has duplicated `_infer_numeric_columns`, `_infer_categorical_columns` functions.

**Fix:**
```python
# base.py
class ColumnInferenceMixin:
    @staticmethod
    def infer_numeric(df: pl.DataFrame, columns: Sequence[str] | None, exclude: Sequence[str] = ()) -> List[str]:
        if columns is not None:
            return list(columns)
        return [n for n, t in zip(df.columns, df.dtypes) 
                if t.is_numeric() and n not in exclude]
    
    @staticmethod
    def infer_categorical(df: pl.DataFrame, columns: Sequence[str] | None, exclude: Sequence[str] = ()) -> List[str]:
        if columns is not None:
            return list(columns)
        return [n for n, t in zip(df.columns, df.dtypes) 
                if t in (pl.String, pl.Categorical) and n not in exclude]

class BaseTransformer(Transformer, ColumnInferenceMixin):
    def _validate_fitted(self) -> None:
        if not getattr(self, "is_fitted_", False):
            raise RuntimeError(f"{self.__class__.__name__} is not fitted. Call fit() first.")
```

```python
import polars.selectors as cs

@staticmethod
def infer_numeric(df: pl.DataFrame, columns: Sequence[str] | None) -> List[str]:
    if columns is not None:
        return list(columns)
    return df.select(cs.numeric()).columns

@staticmethod
def infer_categorical(df: pl.DataFrame, columns: Sequence[str] | None) -> List[str]:
    if columns is not None:
        return list(columns)
    return df.select(cs.string() | cs.categorical()).columns
```
