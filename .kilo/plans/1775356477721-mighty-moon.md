## Key Points to Document

1. **API**: `transform(df: DataFrameOrLazy) -> DataFrameOrLazy` - input type preserved
2. **fit() is always eager**: All `fit()` methods collect LazyFrame if passed
3. **Use `.lazy()` to start**: `df.lazy()` → transformers → `.collect()` at the end
4. **Benefits**: Query optimization, lazy evaluation, memory efficiency for large datasets
5. **Category A (fully lazy transform)**: MathFeatures, RelativeFeatures, CyclicalFeatures, OneHotEncoder, BinaryEncoder, HashEncoder
6. **Category B (lazy transform, eager fit)**: OrdinalEncoder, MeanEncoder, WoEEncoder, CountFrequencyEncoder, LeaveOneOutEncoder, KBinsDiscretizer, QuantileDiscretizer, SimpleImputer, MeanImputer, MedianImputer, StandardScaler, MinMaxScaler, RobustScaler
7. **Category C (always eager - sklearn/Python loops)**: DecisionTreeEncoder, DecisionTreeDiscretizer, KMeansDiscretizer, KNNImputer, IterativeImputer, CrossFitTransformer, MDLPDiscretizer, ChiMergeDiscretizer, IsotonicBinningDiscretizer

## Example Code Snippet for Documentation

```python
import polars as pl
from feataz import OneHotEncoder, MathFeatures

# LazyFrame pipeline for large datasets
lazy_df = pl.DataFrame({
    "category": ["a", "b", "a", "c"] * 100000,
    "value": [1.0, 2.5, 0.5, 3.2] * 100000,
}).lazy()

# Transformations are lazy - no computation yet
result = (
    OneHotEncoder(["category"])
    .fit_transform(lazy_df)  # fit() collects internally, transform() returns LazyFrame
)

# Add more lazy operations
result = MathFeatures(columns=["value"], unary_ops=["log", "sqrt"]).fit_transform(result)

# Only now the query is executed
final_df = result.collect()
```
