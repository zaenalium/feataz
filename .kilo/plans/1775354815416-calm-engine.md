# LazyFrame Support Implementation Plan

## Overview

Add Polars LazyFrame support to feataz with **full scope** and **preserve input type** API design.

**Scope:** All transformers that can support lazy transforms (~15 files)
**API:** LazyFrame in → LazyFrame out, DataFrame in → DataFrame out

## Scope Analysis

### Current State
- All 291 `pl.DataFrame` type hints across 15+ source files
- Zero LazyFrame support currently
- `_ensure_polars_df()` only accepts DataFrame
- All transformers require eager execution

### Transformer Categories

| Category | Description | Lazy Support |
|----------|-------------|--------------|
| **A: Fully Lazy** | Transform uses only expressions | Full support |
| **B: Eager Fit, Lazy Transform** | Fit needs stats, transform is expression-based | Partial support |
| **C: Always Eager** | Uses sklearn or complex Python logic | No lazy support |

**Category A (Full Lazy Support):**
- `MathFeatures`, `RelativeFeatures`, `CyclicalFeatures`
- `OneHotEncoder.transform`, `BinaryEncoder.transform`
- `HashEncoder.transform`

**Category B (Lazy Transform Only):**
- `OrdinalEncoder`, `MeanEncoder`, `WeightOfEvidenceEncoder`
- `CountFrequencyEncoder`, `LeaveOneOutEncoder`
- `KBinsDiscretizer`, `QuantileDiscretizer`
- `SimpleImputer`, `MedianImputer`, `MeanImputer`
- `StandardScaler`, `MinMaxScaler`, `RobustScaler`

**Category C (Eager Only - sklearn dependent):**
- `DecisionTreeEncoder`, `DecisionTreeFeatures`, `DecisionTreeDiscretizer`
- `KMeansDiscretizer`, `KNNImputer`, `IterativeImputer`
- `CrossFitTransformer`, `IsotonicBinningDiscretizer`

## Implementation Plan

### Phase 1: Foundation (base.py)

1. **Add type variables and unions:**
   ```python
   from typing import TypeVar, Union
   
   FrameType = TypeVar('FrameType', pl.DataFrame, pl.LazyFrame)
   DataFrameOrLazy = Union[pl.DataFrame, pl.LazyFrame]
   ```

2. **Create helper functions:**
   ```python
   def _ensure_polars_frame(df: DataFrameOrLazy) -> DataFrameOrLazy:
       """Accept DataFrame or LazyFrame, return as-is."""
       
   def _ensure_eager(df: DataFrameOrLazy) -> pl.DataFrame:
       """Collect LazyFrame to DataFrame if needed."""
       if isinstance(df, pl.LazyFrame):
           return df.collect()
       return df
   ```

3. **Update Transformer base class:**
   - `fit(df: pl.DataFrame)` - stays eager (needs statistics)
   - `transform(df: FrameType) -> FrameType` - preserves input type
   - `fit_transform(df: pl.DataFrame) -> pl.DataFrame` - stays eager

4. **Update ColumnInferenceMixin:**
   - Use `df.collect_schema().names()` instead of `df.columns`
   - Use `df.collect_schema().dtypes()` instead of `df.dtypes`

5. **Update ValidationMixin:**
   - `validate_columns_exist()` - use schema
   - `validate_non_empty()` - handle LazyFrame

### Phase 2: Update Core Transformers

**Priority order:**
1. `features.py` - MathFeatures, RelativeFeatures, CyclicalFeatures (fully lazy)
2. `encoders.py` - OneHotEncoder, OrdinalEncoder, MeanEncoder, etc.
3. `discretize.py` - KBinsDiscretizer, QuantileDiscretizer
4. `impute.py` - SimpleImputer, MedianImputer
5. `scale.py` - StandardScaler, MinMaxScaler

### Phase 3: Tests

Add tests for LazyFrame support:
- Test that LazyFrame input returns LazyFrame output
- Test that DataFrame input returns DataFrame output
- Test that lazy operations can be collected correctly

## API Design Decision

**Option A: Preserve Input Type (Recommended)**
```python
def transform(self, df: FrameType) -> FrameType:
    # Returns same type as input
```

**Option B: Always Return DataFrame**
```python
def transform(self, df: DataFrameOrLazy) -> pl.DataFrame:
    # Always collects and returns DataFrame
```

**Option C: Explicit Mode**
```python
def transform(self, df: pl.DataFrame, lazy: bool = False) -> pl.DataFrame | pl.LazyFrame:
    # User specifies output type
```
